# جست‌وجوگر تصاویر محصول

ابزاری فارسی و بدون نیاز به پایگاه‌داده برای جست‌وجو، بررسی و گردآوری تصاویر محصولات. ورود کاربری ندارد؛ صفحهٔ اصلی در `/image-finder` در دسترس است.

## راه‌اندازی

1. PHP 8.3 یا بالاتر، Composer و Node.js 24 را نصب کنید. افزونه‌های PHP `curl`، `fileinfo` و `imagick` با پشتیبانی WebP لازم‌اند؛ برای خروجی ZIP نیز افزونهٔ `zip` را فعال کنید.
2. فایل محیط را بسازید و راه‌اندازی کامل را اجرا کنید:

   ```powershell
   Copy-Item .env.example .env
   composer setup
   php artisan serve
   ```

3. برای پردازش جست‌وجوها، در یک ترمینال جداگانه worker فایل‌محور را اجرا کنید:

   ```powershell
   php artisan image-finder:work
   ```

   اجرای `php artisan image-finder:work --once` فقط کارهای در صف را پردازش می‌کند و سپس خارج می‌شود. در سرور، worker را با سرویس مدیریت پردازش مانند Supervisor یا Windows Service زنده نگه دارید. برای افزایش هم‌زمانی، چند worker اجرا کنید؛ قفل فایل مانع پردازش هم‌زمان یک محصول توسط چند worker می‌شود.

## توسعه

```powershell
composer test
npm run build
```

برای اجرای سرور توسعهٔ Laravel و Vite از `composer run dev` استفاده کنید؛ worker پردازش تصویر را جداگانه اجرا کنید.

## بدون پایگاه‌داده

این ابزار از هیچ پایگاه‌داده یا جدول Laravel استفاده نمی‌کند. نشست و کش روی فایل هستند و صف محصولات و اطلاعات دسته‌ها به‌صورت JSON در `storage/app/private/image-finder/batches` نگهداری می‌شود. دسته‌های هر مرورگر با شناسهٔ نشست فایل‌محور جدا می‌شوند؛ ورود کاربری لازم نیست. هیچ دستور migration یا راه‌اندازی پایگاه‌داده لازم نیست. از پوشهٔ `storage/app/private/image-finder` نسخهٔ پشتیبان تهیه کنید؛ فایل‌های تصویر طبق تنظیمات در دیسک انتخاب‌شده ذخیره می‌شوند.

## ورودی و خروجی

- یک محصول همراه با برند، مدل، دسته‌بندی و توضیحات اختیاری
- چند محصول، هر نام در یک خط
- فایل JSON شامل فهرست محصولات یا شیء دارای `products` و `settings`
- خروجی JSON و آرشیو ZIP برای هر دستهٔ جست‌وجو
- توقف، ادامهٔ جست‌وجوهای ناتمام و بازبینی دستی تصاویر

نمونهٔ کوتاه فایل JSON:

```json
{
  "products": [
    {
      "id": "sku-1001",
      "name": "Samsung Galaxy A02",
      "brand": "Samsung",
      "model": "SM-A026E",
      "images": 3,
      "search_terms": ["Samsung Galaxy A02 official product images"]
    }
  ],
  "settings": {
    "min_width": 800,
    "min_height": 800,
    "language": "en",
    "image_format": "webp"
  }
}
```

## منابع جست‌وجو و مجوزها

Wikimedia Commons به‌صورت پیش‌فرض فعال است. Openverse به شناسه و رمز API نیاز دارد؛ SerpApi و DataForSEO اختیاری و پولی هستند. مقادیر `OPENVERSE_CLIENT_ID`، `OPENVERSE_CLIENT_SECRET`، `SERPAPI_API_KEY`، `DATAFORSEO_LOGIN` و `DATAFORSEO_PASSWORD` را فقط در `.env` قرار دهید. هر منبع را می‌توان با متغیرهای `IMAGE_FINDER_*_ENABLED` فعال یا غیرفعال کرد. API قدیمی Bing Search در اوت ۲۰۲۵ بازنشسته شده و استفاده نمی‌شود.

تصویرها پیش از ذخیره از نظر نشانی عمومی HTTPS، سیاست robots، نوع و امضای فایل، ابعاد، سلامت تصویر و تکراری‌بودن بررسی می‌شوند. فقط تطبیق‌های مطمئن با مجوز روشن خودکار تأیید می‌شوند. تصویرهای دارای مجوز نامشخص یا تطبیق کم‌اطمینان برای بازبینی دستی می‌مانند؛ تأیید دستی مجوز انتشار ایجاد نمی‌کند. محدودیت تلاش، زمان، حجم فایل و تعداد درخواست‌ها در `.env.example` مستند شده است.

## دسترسی و امنیت

طبق درخواست، صفحهٔ ورود حذف شده است؛ هر بازدیدکننده می‌تواند جست‌وجو ثبت کند، اما فهرست و جزئیات دسته‌ها فقط در همان نشست مرورگر قابل مشاهده است. محدودیت درخواست فعال است، اما برای استقرار عمومی، دسترسی سایت را در وب‌سرور یا فایروال به کاربران موردنظر محدود کنید تا از مصرف API و منابع جلوگیری شود. کلیدهای API هرگز در مرورگر نمایش داده نمی‌شوند.
